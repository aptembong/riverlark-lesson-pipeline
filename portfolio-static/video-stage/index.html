Pronunciation flags

5 flagged in this lesson

Some words are spelled the same but said two ways, like read (“reed” now, “red” in the past). The script step flags each one and records which is meant, and the list goes to the vendor with the storyboard.

SceneLineSay it as
S1As we read, we'll look for the plot.reed (present tense)
S3She read it every night that week.red (past tense)
S3Where had she read the book last?red (past tense)
S6She found it by thinking back to where she read it last.red (past tense)
S7Next time you read a story, look for the problem, and how it gets solved.reed (present tense)

Known issue in this sample: the stand-in voice didn’t use these flags, so you may hear read in the wrong tense. A production voice reads them from a pronunciation dictionary, and the speech-to-text check in Stage 6 catches anything that still slips.

How this sample was built

1 · Narrate

Voice and word timing

An open-source voice model (Kokoro) reads each sentence on its own, so every sentence's start and end time is exact. Word times inside a sentence are spread by syllable count, which is close enough for a reading highlight.

2 · Draw

Frames from the storyboard

A Python script draws each 1080p frame from the storyboard and the narration timeline, one encoded file per scene, then joins them and adds the sound with ffmpeg.

3 · Check

Same checks as production

The checks above read only the finished file, the caption file and the storyboard, so they run unchanged on a vendor's video.

What this sample doesn't show

  • Pronunciation: the stand-in voice sometimes says read in the wrong tense. Production uses a commercial voice (ElevenLabs or the vendor’s narrator) with the pronunciation flags, and the speech-to-text check catches anything that still slips.
  • The captions come from the narration timeline, so the same speech-to-text check also confirms the audio says what the captions say.
  • The voice is a stand-in for the vendor's narrator, and word highlight timing is estimated within each sentence.
  • The licensed Lexile check and the 10% human pacing review happen in production and weren't run here.
