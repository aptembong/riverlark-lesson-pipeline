# Portfolio backup copies

Offline copies of every page in the [Riverlark case study](https://claude.ai/artifact/8cQtYZuDdt3jodLvn8Akp1), in case the live links are ever unavailable. Each folder has the page as **HTML** (clickable, with its tabs and practice activities) and a **PDF** of its main view.

## How to open them

GitHub shows HTML files as code, so download them first:

1. Go to the [repository's main page](https://github.com/aptembong/riverlark-lesson-pipeline).
2. Click the green **Code** button, then **Download ZIP**.
3. Unzip the file and open `portfolio-static/index.html` in any web browser.

To read a single PDF, click it in GitHub. It opens right in the browser.

## What's here

| Folder | Page |
|---|---|
| `case-study/` | Case study hub: overview, discovery, pipeline, quality and governance, enablement, evidence, scale |
| `lesson-studio/` | Lesson Studio: one lesson through Stages 2 to 5 (replay works offline; live drafting needs Claude) |
| `video-stage/` | The sample video lesson, script, storyboard and video checks (plays the video from `video/`) |
| `reviewer-guide/` | Reviewer guide and desk card for editors |
| `onboarding-and-practice/` | Writer and editor onboarding with a practice round |
| `rollout-plan/` | Rollout plan with gates, measures and a cost calculator |
| `prompt-change-process/` | Prompt change process with a request form |

Links inside the copies point to the live pages.
